## 🎤 How to Use

1. Pick a city from the state folders
2. Copy the lyrics
3. Paste into Suno, Udio, or your preferred AI music generator
4. Set genre to match the vibe (Pop, R&B, Hip-Hop, Country, etc.)
5. Generate and enjoy!

## 📋 Song Format

Each song includes:
- **Title** — City name + state
- **Genre suggestion** — Best musical style for the vibe
- **Lyrics** — Full song with verses, chorus, bridge
- **Local references** — Landmarks, culture, history, people
- **Suno tags** — Ready-to-paste tags for Suno AI
